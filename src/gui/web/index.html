只读扫描机器档案“项目父级”下的 git 仓库和项目清单。点每行的“操作”打开弹层，选择挂载方式并预演后再执行。

“本地忽略（exclude）”是什么？

“本地忽略”指项目根目录的 .git/info/exclude 中的忽略规则。它只在本机生效，让工作台写入的入口文件不出现在 git status 里；不会修改 .gitignore，也不会提交到仓库。取消挂载时只移除工作台添加的那一行，文件里原有的其他忽略规则保持不变。

项目操作

取消挂载只移除工作台块；工作台创建且移除后为空的文件才删除。已挂载项目要改用写另一个文件的模式（AGENTS.md 与 AGENTS.local.md 之间切换），先取消挂载再重新挂载。

立即备份只读取当前入口并写入本地 state/backups，不改动工具目录。清理旧备份默认只预演，确认后才删除超出保留份数的备份，每工具最近一份始终保留。恢复默认只预演；执行恢复前会先把当前入口另存一份备份。
