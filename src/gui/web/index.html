选择全部或单个工具，把 content/ 中的规则与技能接入它们的入口；设置页新增的自定义工具也会出现在目标列表中。

卸载工作台

按上方“目标工具”选择范围；“全部”会同时移除全局脚本 junction。只移除工作台块、工作台创建的文件、本工作台生成且未改动的记忆拆分文件和指向本仓库的技能 junction，保留用户内容、全局工作台目录与备份。

先选择目标工具，“加载预演”才会启用。合并只改写工作台块正文；块前、块后原文必须保持原样，改动块外内容会被校验拒绝。写入前会备份入口，写后核对字节与块哈希，失败自动回滚。入口不是可写文本或工作台块标记异常时，页面不会开放写入。工具设置了版本要求且当前版本不符或无法检测时，合并会被阻止。

“本地忽略（exclude）”是什么？

“本地忽略”指项目根目录的 .git/info/exclude 中的忽略规则。它只在本机生效，让工作台写入的入口文件不出现在 git status 里；不会修改 .gitignore，也不会提交到仓库。取消挂载时只移除工作台添加的那一行，文件里原有的其他忽略规则保持不变。

设置：管理本机参数与自定义工具

这里修改只影响本机的机器档案：备份保留份数、GUI 端口、路径变量、内置工具的路径与版本要求，以及工作台尚未内置支持的自定义工具。

执行结果：所有修改先预演，确认后备份并原子写入机器档案；部署、合并、状态检查随后按新设置工作。版本要求留空表示不核对；填写后，部署、合并与备份恢复写入前会核对当前工具版本，不符或无法检测时阻止写入（备份恢复可用 --force 覆盖）。版本可写精确值、比较范围或用 || 分隔的多个候选，英文括号可改变优先级。新增的自定义工具会出现在部署页的“目标工具”里，可单独预演与执行，即使配置目录或入口还不存在，也会按填写的路径创建父目录后写入。

设置直接写入本机机器档案，只影响这台机器，不会提交到仓库。修改默认只预演；执行前需确认，写入前会备份原档案。路径可用 ${NAME} 或 %NAME% 引用下面的环境变量；工具路径留空表示沿用注册表默认值。

备份清理按此份数保留每个工具的最近备份，最近一份始终保留。命令行 --keep 优先。

0 表示每次自动分配；命令行 --port 优先于这里的值。

环境变量

变量值只保存在本机机器档案。清空变量值表示删除该变量；名称只能用字母、数字和下划线，且不能以数字开头。

工具路径覆盖

“继承”表示沿用注册表默认值。填写入口覆盖后不再尝试该工具的备选入口；配置目录不存在时该工具视为未安装。停用工具不会删除已有入口，只影响后续部署和状态检查。版本要求留空表示不核对；填写后支持精确版本（如 3.4.13）、比较范围（如 >=3.3,<4）和多个候选（如 3.4.13||3.5.0）。逗号表示同时满足且优先于 ||，英文括号可改变优先级（如 >=3.3,(<4||3.4.13)），<> 表示不等于。部署、合并与备份恢复会先核对，不符或无法检测时阻止写入。检测来源显示在每个工具卡片下方。

自定义工具

用于接入工作台尚未内置支持、或本机还没安装的工具。点页面顶部的“添加自定义工具”在弹层中填写；加入列表后仍是未保存状态，需点下方“预演修改”并确认写入才会保存到机器档案。保存后它会出现在部署页的“目标工具”中，可单独部署；部署不要求配置目录已存在，会按“入口文件”与“技能目录”创建父目录后写入。工具 id 用小写字母、数字和短横线，保存后不可修改；入口与路径必须是绝对路径或以 ~ 开头的本机路径。版本要求可选，留空不核对；填写后从配置目录下的状态或版本清单文件读取当前版本，不符或无法检测时阻止部署、合并与备份恢复。版本可写精确值、比较范围、用 || 分隔的多个候选，或用英文括号组合；逗号表示同时满足且优先于 ||。删除同样要先预演并确认，写入前不会改动机器档案。

修改任意设置后，“预演修改”和“放弃修改”才会启用；放弃修改会从机器档案重新加载，丢弃尚未写入的页面改动。

添加自定义工具

填写后点“加入列表”，会先成为未保存的卡片；再点设置页底部的“预演修改”，确认写入后才会保存到机器档案，并出现在部署与合并的目标列表中。

路径可以引用设置页定义的环境变量，但必须是绝对路径或以 ~ 开头；路径不合规或引用了未定义变量时，“预演修改”会标出并阻止写入。加入列表后仍可在卡片里继续编辑字段。

备份：给入口文件留一份可恢复的副本

“立即备份”把各工具当前入口复制到本机 state/backups，下方列表可预览并恢复。部署写入前也会自动备份；设置写入另存到 state/settings-backups。

执行结果：备份本身不改动工具目录。恢复默认只预演，确认后先把当前入口另存一份备份，再写回所选备份；清理只删除超出保留份数的旧备份，每个工具最近一份始终保留。

立即备份只读取当前入口并写入本地 state/backups，不改动工具目录。没有备份时“清理旧备份”保持禁用。清理默认只预演，确认后才删除超出保留份数的备份，每工具最近一份始终保留。恢复默认只预演；执行恢复前会先把当前入口另存一份备份。工具设置了版本要求且当前版本不符或无法检测时，恢复会被阻止；预览后可勾选强制覆盖。

历史：查看本机操作日志与部署记录

本页读取 state/logs 下的月度操作日志和 state/deploy-state.json 的部署记录。日志只记录动作、目标、结果与备份路径，不记录文件正文或访问令牌。

执行结果：本页只读，不改任何文件、不触发部署。部署、合并、备份、恢复、卸载、项目挂载、设置或内容写入成功后，会在“操作记录”里新增条目；部署记录与漂移项反映当前状态，可用来判断哪些工具需要重新部署或手工合并。

操作记录按写入顺序倒序显示，只包含实际写入或失败的写操作，预演不记录。部署记录来自当前状态文件；漂移项按入口与构建实时检查，不是历史快照。

诊断：把本机状态、哈希、日志与路径清单打包

本页先读取部署状态、构建与入口哈希、体检结果和操作日志，用于判断入口为什么没有生效、哪些工具待重新部署；确认后生成诊断目录与 zip，保存在 state/diagnostics。

执行结果：刷新只读，不写文件。生成后会在 state/diagnostics 下得到包含 summary、status、doctor、log、paths 与 README 的诊断目录和 zip；包内包含本机路径与主机名，但不含机器档案正文、环境变量值、规则或入口正文、令牌与密钥，发给他人前仍需自行复核。

刷新会并行读取 status、log 与 doctor，只用于显示，不写文件。确认生成后，页面会把诊断目录与 zip 的实际路径、包内文件和体检摘要列在下方；诊断包只写入本机 state/diagnostics，不会上传。
