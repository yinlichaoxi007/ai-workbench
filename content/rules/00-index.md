# AI 工作台通用规则

本目录是跨 AI 工具的唯一真源。各工具的全局入口由 `aiwb deploy` 生成，入口只放摘要与索引，规则正文以本目录为准。

## 阅读顺序

1. `01-communication.md`：沟通方式与协作偏好。
2. `02-workflow.md`：动手前后的工作铁律。
3. `03-coding.md`：编码、注释与提交规范。
4. `machines/<主机名>.md`：本机路径、环境与项目清单。

## 生效顺序

1. 用户当前指令。
2. 项目仓库自身的 `AGENTS.md` 或其他项目规则。
3. 本工作台通用规则。
4. AI 工具默认习惯。

发生冲突时按上述顺序执行。高优先级规则与本工作台冲突时，以高优先级为准，并明确指出冲突点。

## 使用约定

- 需要资料目录、项目父级、工具链版本时，读本机档案，不要猜。
- 需要某条规则的细节时，读对应文件，不要凭记忆补写。
- 项目规则可能比工作台更严格；不要用工作台规则去覆盖项目规则。
- 修改规则：改本仓库 → `aiwb build` → `aiwb deploy`，不要直接编辑各工具目录中的副本。
- 新机器：复制 `machines/_template.md`，填写后再部署；本机档案只保存在本机，不入库。

## 文件职责

| 文件 | 职责 |
|---|---|
| `00-index.md` | 总索引、优先级、维护约定 |
| `01-communication.md` | 交流方式、提问与方案表达 |
| `02-workflow.md` | 调研、修改、测试、删除、提交 |
| `03-coding.md` | 代码质量、注释、安全、复用 |
| `machines/<主机名>.md` | 只属于该机器的路径、环境和项目信息 |
