# 可部署脚本

本目录存放要部署到全局工作台的通用脚本。部署时整个目录以 junction 安装为 `<全局工作台>/scripts/ai-workbench`，不复制文件。

- 只放跨工具、跨项目可复用的脚本；本仓库自身的维护、部署、校验、打包脚本放仓库根目录的 `scripts/`，不部署。
- 脚本使用 Node.js 内置模块，零 npm 依赖，可直接 `node <脚本>` 执行。
- 脚本不写本机绝对路径；仓库位置、全局工作台等路径从机器档案、参数或环境变量读取。
- 脚本顶部注释说明用途、参数、输出和退出码；较长的用法写到 `docs/`。
- 本机专用脚本不要放这里，放到 `<全局工作台>/scripts/` 下的其他子目录，避免混进仓库。
